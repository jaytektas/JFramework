# Contributor Licence Agreement

## Why this exists

JFramework is GPLv3. That licence binds everyone who receives the code — but not
its copyright holder, who needs no licence from himself. Today that is one
person, so he can also ship applications built on this framework under other
terms, including closed ones.

The moment a contribution is merged, that stops being true for the part you
wrote: you would hold copyright on it, and the project would only have it under
GPLv3. One accepted patch is enough to remove an option the project currently
has.

This agreement keeps that option open. **You keep the copyright in your work.**
You grant the project a licence broad enough to relicense it — which is what the
GPL alone does not give — so the project can continue to be offered under other
terms as well as GPLv3.

If you would rather not grant that, say so. A contribution can still be useful
as a bug report, a failing test, or a description of the fix, and none of those
need this agreement.

## How to agree

Add your name to `CONTRIBUTORS.md` in the same change as your first
contribution, and sign off each commit:

    git commit -s

The sign-off records that you have read this agreement and that the commit is
submitted under it.
